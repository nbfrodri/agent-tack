# Feature toggles that `harness config` lists, reads and writes. Add a feature by adding a line.
# Columns: name, git config key, default, allowed values (bool, number: a positive integer,
#          decimal: a positive amount, text: any non-empty value, or alternatives such as auto|off), scope (any: project or
#          global; global: user-wide only), enforcement (hook: a hook guarantees it; mod: a Claude
#          Code mod guarantees it; instruction: the assistant follows it; installer: install.sh
#          reads it), description.
# Safety checks (secret scanning, the command guard, protected main and tags) are deliberately
# absent: they keep their one-off overrides, described in docs/usage.md.
#
# name                key                          default  values    scope   enforcement  description
context               harness.context              true     bool      any     instruction  Load project instructions, the docs index and the handoff check at session start
conventional-commits  harness.conventionalCommits  true     bool      any     hook         Enforce Conventional Commits in enabled projects
delegation            harness.delegation           auto     auto|off  any     instruction  Delegate separable strict-level work to subagents automatically
mods                  harness.mods                 true     bool      global  installer    Install the harness's Claude Code mods (usage band, activity pane)
vscode-agents-md      harness.vscodeAgentsMd       true     bool      global  installer    Turn on VS Code's chat.useAgentsMdFile so Copilot Chat loads each project's AGENTS.md
stop-check          harness.stopCheck            true     bool      any     hook         Before the assistant stops, report uncommitted work, a failing fast check, a stale handoff or docs the docs map expects
reply-style           harness.replyStyle           normal   normal|terse      any  instruction  Ask the assistant for terse replies to save output tokens
skill-loading         harness.skillLoading         normal   normal|minimal    any  instruction  Load skills only when a task cannot be done without them, to save input tokens
subagent-model        harness.subagentModel        inherit  inherit|economical any instruction  Delegate to the most economical capable model instead of inheriting the main one
check-fast            harness.checkFast            none     text      any     hook         Shell command run after each edit in trusted projects; its failures are shown to the assistant
unleash-max-tool-calls harness.unleashMaxToolCalls none    number    any     hook         In a project-only mode such as unleash, refuse tool calls after this many in one session
unleash-max-cost      harness.unleashMaxCost       none     decimal   any     mod          In a project-only mode such as unleash, refuse tool calls once the session cost passes this many USD
