# Provider-neutral model tiers and the model each tool uses for them. Workflow rules and skills
# speak only in tiers; `tack models [TIER]` turns a tier into the current tool's model. Override
# or extend this per machine in ~/.config/agent-tack/model-tiers.txt (same columns; your lines win).
#   economical  fast and cheap: mechanical, well-specified work (docs, renames, fixtures)
#   balanced    standard implementation following existing patterns
#   strongest   design-heavy or risky work (architecture, security, tricky bugs)
# "inherit" keeps the current model. A plain model name pins exactly that model.
# "family:NAME" selects the visible Codex catalog model ending in -NAME with lowest priority
# (ties: last lexical slug). The optional fourth column is a pinned fallback, else inherit.
# Other tools and unavailable catalogs use the fallback. The family-to-tier map is edited by hand;
# Claude aliases already follow the latest model. Account-specific overrides use the same syntax.
# Every tool with an agents directory in targets.txt needs all three tiers (tests/validate.sh).
