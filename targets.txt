# AI tools the installer configures. Paths come from each tool's documentation.
# Columns (- means no managed integration; it does not claim the tool lacks that capability):
#   tool          name
#   when          always | detect (configure only if the tool is installed)
#   commands      commands that detect the tool (comma-separated)
#   instructions  global instructions file
#   skills        extra skills dir (the tool also reads ~/.agents/skills)
#   agents        subagents dir the installer fills
#   hooks         hooks file the installer fills
#   min_version   oldest supported version (x.y.z)
#   smoke         non-interactive diagnostic arguments run by 'tack doctor --tools' (comma-separated)
# Older files with only the first five columns are still read. Every tool also gets the skills
# in ~/.agents/skills, the open standard location.
#
# tool      when      commands              instructions                          skills              agents            hooks                    min_version  smoke
