# Sets: named bundles of skills, agents and Claude Code plugins for one kind of work.
# Lines:  set  about   one-line description
#         set  skill   NAME                 a skill of this repository (skills/NAME)
#         set  skill   SOURCE:PATH          a skill folder in a collection pinned in sources.txt
#         set  agent   NAME                 a role of this repository (agents/NAME.md)
#         set  plugin  PLUGIN@MARKETPLACE   Claude Code only; its marketplace is in plugins.txt
# Activate one in a project with `tack set use NAME` (linked for every tool, ignored by git) or
# everywhere with `tack set use NAME --global` and ./install.sh. Every active skill adds its
# description to each session, so keep sets focused and activate them where the work happens.
# Two different skills may not share a name; the same skill may appear in several sets.
