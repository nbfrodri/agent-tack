# Security policy

This is a personal configuration repository, public to read or fork; see
[ADR 0004](docs/adr/0004-personal-configuration-with-sets.md). Only the latest
`main` is supported.

Report vulnerabilities privately using GitHub's **Report a vulnerability** button
in this repository's **Security** tab (private vulnerability reporting). Do not
report vulnerabilities through public issues.

Scope includes the installer, hooks and command guard. Third-party skills pulled
through sets keep their own security policies; see [audits](docs/audits) and
[sets](docs/sets.md).
