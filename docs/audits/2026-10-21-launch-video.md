# Audit: launch-video skills

- Date: 2026-10-21. Scope: the seven skill folders selected by `launch-video` in `sets.txt`: `brag` and `brag-slim` from `latent-spaces/brag` at `069432cac935ed1895859df201c31436c07fb74e`, and `hyperframes-core`, `hyperframes-animation`, `hyperframes-creative`, `hyperframes-keyframes` and `hyperframes-cli` from `heygen-com/hyperframes` at `ffcef8f886b4a1ed9dba12f21b9939db5c17746e`. Inventory: 516 files, including 245 UTF-8 text files, 265 audio assets and six fonts. Both checkouts were read-only and their HEADs matched these pins.
- Method: follow the [external-skills audit](2026-10-11-external-skills.md): scan text for pipe-to-shell installs, `sudo`, global installs, destructive commands, permission bypass, credential paths and secret variables, network sends, telemetry, instruction overrides, agent settings writes and dynamic execution; read hits in context. Run `skill-scanner` on all seven folders, then supplement its zero findings with recursive searches covering HTML, nested recipes and `.mjs` helpers that its main content scan misses. Check hidden Unicode, symlinks, hook/MCP files and frontmatter. Separately search prose for instructions to fetch rules, install skills or obtain code at run time; trace dependencies outside the set.
- Limits: static review of the pinned skill text and bundled scripts, not an execution or dependency audit. No skill commands, installs, rendering, cloud operations or feedback submissions were run. Audio/font binaries and downloaded npm/Python packages, models, browser binaries, registry components and remote skills were not reviewed. CLI behavior described below is what the skills document; the npm implementation was not verified. The sibling plugin-installation reference was read to understand its conditional protection, but the omitted skills were not audited in full. Repeat after either pin changes; a skill pin does not freeze its runtime downloads.

Paths below are relative to each collection's pinned checkout; `skills/brag*` belongs to `brag`, and `skills/hyperframes*`, `skills/media-use`, `skills/slideshow` and `skills/figma` belong to `hyperframes`.

## Result

Install with caution. No direct instruction to steal credentials, override higher-priority instructions, conceal actions or bypass agent permissions was found. There are no symlinks, hidden Unicode format/tag characters, shipped agent hooks or MCP configurations in the seven folders. The `agents/openai.yaml` file in `hyperframes-keyframes` is display/prompt metadata, not a hook or MCP server. References to layout/contrast bypasses concern video checks, not agent permissions.

The set already isolates these skills from general video work because of the unpinned CLI. Further risks include live skill installation, credential access and public feedback. The decisions below are usage recommendations; this audit changes documentation only, leaving `sets.txt`, `sources.txt` and the cached sources untouched.

## Instructions fetched at run time

The second pass found the two High-severity instruction-loading paths above: `init`/`skills` and the external `animate-text` installation. These are more than vendor documentation lookups. The selected skills otherwise carry their technical rules locally; requests to read the “current” Hyperframes guidance in `skills/brag/references/step-3-compose.md` refer to the installed domain skills, not an explicit remote rules URL.

All five Hyperframes skills link `../hyperframes/references/plugin-installation.md`. That omitted sibling reference tells plugin installations to use a manifest-versioned launcher, disable standalone skill refreshes and report missing bundled skills rather than download replacements. This is conditional on a plugin installation; tack installs selected standalone folders, so those protections cannot be assumed for this set.

## Other observations

- Both `skills/brag/references/step-1-inspect.md:119` and `skills/brag-slim/SKILL.md` exclude secrets and credential material from project inspection and require fictional replacements for personal data before it reaches plans, video or share copy. Slim additionally accepts websites and downloads their visible assets; no fixed exfiltration endpoint is prescribed.
- `skills/brag/SKILL.md` has a model-specific dispatch to `<skill-dir>/slim.md`, a bundled copy of the slim variant that exists in that folder at this pin. The separately selected `skills/brag-slim/SKILL.md` is the standalone version of the same skill.
- Destructive local operations found were temporary-directory cleanup in the helper loaders/tests, documented cache cleanup, and replacement of the generated `brag.mp4` with its poster-adjusted output (`skills/brag/references/step-4-deliver.md`). No pipe-to-shell install, `sudo` or global-install command was found in the selected folders. The cloud destruction examples remain consequential and are listed separately above.
