## What's good
- Idempotent installer that backs up instead of overwriting and keeps user hooks (`#agent-config` tag).
- Hook chaining with recursion guards and per-repo opt-out; two independent layers protect `main` (git hook and GitHub ruleset).
- Isolated tests (temp HOME, XDG, `GIT_CONFIG_NOSYSTEM`) on Linux and macOS.
- Short skills with progressive disclosure through `references/`; homogeneous reviewer reports.
